# java-digital-asset-management
객체지향 프로그래밍 기반 디지털 자산 관리 시스템 개발 (Java 3분반 프로젝트)
 # 객체지향 프로그래밍 기반 디지털 자산 관리 시스템 개발

## 1. 프로젝트 개요

- 분반: 3분반
- 프로젝트 주제: 객체지향 프로그래밍 기반 디지털 자산 관리 시스템 개발
- 개발 언어: Java
- 개발 환경: Visual Studio Code
- 버전 관리: Git / GitHub

## 2. 프로젝트 목적

객체지향 프로그래밍의 원리를 기반으로 디지털 자산을
체계적으로 관리할 수 있는 시스템을 개발한다.

디지털 자산의 등록, 수정, 삭제, 조회, 검색 기능과
사용자별 자산 배정 및 회수 기능을 구현한다.

개발 과정에서 객체의 상태, 행동, 책임을 명확하게 정의하고,
객체 간의 관계를 설계하여 객체지향 프로그래밍에 대한
이해도를 높이는 것을 목표로 한다.

## 3. 주요 기능

| 번호 | 기능 | 설명 |
| --- | --- | --- |
| F-01 | 자산 등록 | 새로운 디지털 자산 등록 |
| F-02 | 자산 수정 | 기존 자산의 정보 수정 |
| F-03 | 자산 삭제 | 등록된 자산 삭제 |
| F-04 | 자산 목록 조회 | 전체 디지털 자산 조회 |
| F-05 | 자산 검색 | 조건에 따른 디지털 자산 검색 |
| F-06 | 자산 배정 | 특정 사용자에게 자산 배정 |
| F-07 | 자산 회수 | 사용자에게 배정된 자산 회수 |

## 4. 설계 원칙

- 핵심 객체를 최소 3개 이상 도출한다.
- 각 객체의 상태, 행동, 책임을 명확하게 정의한다.
- 캡슐화를 통해 객체의 상태를 보호한다.
- 객체 간의 역할과 책임을 분리한다.
- 설계 다이어그램과 실제 구현의 일관성을 유지한다.
